## Cómo trabajo

- **Web rápida:** Astro, Tailwind v4 y TypeScript; React solo cuando hace falta interactividad.
- **Herramientas:** Python y Flet para CLI y escritorio, con pytest cuando el código se reutiliza.
- **Entrega:** `pnpm --frozen-lockfile` → build → GitHub Actions → Pages/Cloudflare.
- **Detalle:** SEO técnico, canonical, sitemaps y builds reproducibles.
